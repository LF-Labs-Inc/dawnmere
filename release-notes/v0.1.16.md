# Dawnmere 0.1.16

Update with `dawnmere update`, or run the install line again. This release updates the engine to 0.1.14; the CLI, the plugin and the connector are unchanged apart from their version.

- **Forgetting a note now also removes Dawnmere's copy of the Claude Code memory file it came from**, when Claude Code wrote that file with its short "Why:" / "How to apply:" lines. Before, search and the recall tools could still return the forgotten fact from that copy. The copy is taken only when its text, apart from those lines, is your note word for word; a file that says anything else, rewords it, or is not in English is kept. Dawnmere still never deletes Claude Code's own file on disk: the reply names it.
- **Known limit:** when such a copy is taken, the clean-up also clears session-handoff items and chat titles that share a word with its "Why:" / "How to apply:" lines.
