# Dawnmere 0.2.0

Update with `dawnmere update`, or run the install line again. The engine (0.1.14), the plugin and the connector are unchanged from 0.1.16 apart from the plugin's version.

- **Anonymous usage counts.** Dawnmere can now send LF Labs a few counts, at most once a day, so we can tell how many Macs use it, which apps people connect, and whether they keep using it. No memory, prompt or file of yours is ever sent. A new install has it on, and setup asks first, so you can say no there. An install from before 0.2.0 sends nothing until it answers: you are asked once, the next time you run `dawnmere setup` or `dawnmere update` in a terminal.
- **See it and turn it off.** `dawnmere telemetry show` prints exactly what is sent. `dawnmere telemetry off` stops it, and `DO_NOT_TRACK=1` or `LFLABS_MEMORY_TELEMETRY=0` keep it off whatever was answered. [TELEMETRY.md](https://github.com/LF-Labs-Inc/dawnmere/blob/main/TELEMETRY.md) lists every field, and the server's code is in `telemetry/`. It keeps no IP address, keeps single pings for 7 days, then only daily totals with no id in them.
